---- Assistant Médical RAG - Chatbot d'Information Santé----
Chatbot médical intelligent basé sur l'architecture RAG pour fournir des informations de santé fiables, sourcées et sécurisées. Construit avec LangChain, FAISS et Llama 3.1, il intègre des garde-fous éthiques et une détection d'urgences en temps réel.
